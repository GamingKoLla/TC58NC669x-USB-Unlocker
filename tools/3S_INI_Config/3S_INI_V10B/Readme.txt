
SSS alternative INI Configuration Tool
______________________________________
Работоспособность программы проверена на OS Windows 98 - Windows 7



=======[ Файлы ]=======

+ comctl32.Ocx			- компонент ActiveX 
+ comdlg32.ocx			- компонент ActiveX 
+ msvbvm60.dll			- библиотека vbRuntime
+ 3S_INI.exe			- исполняемый файл программы
+ VB6.0-KB290887-X86.exe	- установщик библиотек от Microsoft в случае, если программа не запускается 

+ прочие файлы			- [Readme.txt, 6691_CM.INI, Mpt1.ini, U3S_MP_V2182.exe, папка ISP_CODE]
				  являются необязательными, демонстрируют работу программы и могут быть удалены


=======[Очень краткие комментарии]=======

+ При наведении мышью на НЕКОТОРЫЕ поля отображается всплывающая подсказка
+ Если в папку с программой положить папку ISP_CODE с бинарниками, то они отобразятся в списке. Если имеют расширение *.bin
+ Некоторые настройки требуется сохранять в конфиг прошивальщика MPT1.INI, о чём предупреждается (и не забудьте
  в опциях включить сохранение MPT1.INI)
+ Если в папку с программой положить утилиту-прошивальщик и указать ее имя - после сохранения конфига она запустится
+ В программу перенесены некоторые глюки с зависимостями опций, присутствующие в китайской утилите (на всякий случай)
